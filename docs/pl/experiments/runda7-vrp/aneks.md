# Runda 7 — aneks do prerejestracji (przed jakimkolwiek wynikiem)

Dodany ok. 2 min po zadaniu, po uwadze z boku: zespół = 2 agenty, solo = 1,
więc wygrana zespołu może mierzyć liczbę agentów, nie kanał.

Zapieczętowany werdykt (zespół vs solo Claude) **zostaje bez zmian**.

Dodatkowo, z tymi samymi progami ±2,0 pkt i tym samym protokołem pomiaru:
**zespół vs KONTROLA = lepszy z dwóch niezależnych solo bez kanału**
(solo Claude — już działa — oraz solo Codex, agentmachi_poligon/vrp-codex-solo,
start ok. 3 min po zadaniu; ten sam limit 90 min od JEGO startu).
To porównanie odpowiada na pytanie „ile daje sam kanał". Kontrola jest
lustrzana wobec składu zespołu (Claude + Codex). Ograniczenie: Codex solo
startuje kilka minut później i przez inny harness (subagent rescue).
